RAJASTHAN TOURISM WEBSITE - SOURCE CODE

Files:
1. index.html - website structure and content
2. style.css - design and responsive styling
3. script.js - city data, search and interactions

How to run:
1. Keep all three files in the same folder.
2. Open index.html in Chrome.
3. Search for a city or select one from the list.

Internet is needed for the external Unsplash background image.
